Every element, wrapper and helper in `@randsum/ui` is its own entry. There is
no root import: `import … from '@randsum/ui'` does not exist, so each page
ships only what it uses. Shared code, Lit included, is split into chunks, so
two parts on one page do not load it twice.

## Elements

Importing an entry registers its tag.

| Import                       | Tag                        | Renders                                                       |
| ---------------------------- | -------------------------- | ------------------------------------------------------------- |
| `@randsum/ui/roller`         | `<randsum-roller>`         | The whole roller; `size` is `mini`, `compact` or `max`         |
| `@randsum/ui/scope`          | `<randsum-scope>`          | Nothing: one roller state for the parts inside it             |
| `@randsum/ui/notation-field` | `<randsum-notation-field>` | The input, with each notation token in its modifier's colour  |
| `@randsum/ui/roll-button`    | `<randsum-roll-button>`    | Roll, disabled until the notation is valid; `tip` shows the English |
| `@randsum/ui/status-line`    | `<randsum-status-line>`    | The hint, the error, or the roll in English                   |
| `@randsum/ui/key-pad`        | `<randsum-key-pad>`        | Dice and modifier keys (`keys`)                               |
| `@randsum/ui/preset-list`    | `<randsum-preset-list>`    | Named rolls as chips or a list (`presets`)                    |
| `@randsum/ui/readout`        | `<randsum-readout>`        | The total and every step, or what to do before a roll         |
| `@randsum/ui/roll-steps`     | `<randsum-roll-steps>`     | Just the steps of a roll (`records`, or the last result)      |

A part renders from its `roller` property, or else from the `<randsum-scope>`
around it.

## React

| Import                             | Export          |
| ---------------------------------- | --------------- |
| `@randsum/ui/react/roller`         | `Roller`        |
| `@randsum/ui/react/use-roller`     | `useRoller`     |
| `@randsum/ui/react/notation-field` | `NotationField` |
| `@randsum/ui/react/roll-button`    | `RollButton`    |
| `@randsum/ui/react/status-line`    | `StatusLine`    |
| `@randsum/ui/react/key-pad`        | `KeyPad`        |
| `@randsum/ui/react/preset-list`    | `PresetList`    |
| `@randsum/ui/react/readout`        | `Readout`       |
| `@randsum/ui/react/roll-steps`     | `RollSteps`     |

Each part takes the `roller` that `useRoller` returns.

## Vue

The same set under `@randsum/ui/vue/`: `Roller` (with `v-model`), `useRoller`
(returns `{ roller, snapshot }`) and each part.

## React Native

The same set under `@randsum/ui/native/`, built from native views rather than
wrapping the elements: `Roller`, `useRoller` and each part
(`@randsum/ui/native/notation-field`, `@randsum/ui/native/key-pad`, …), plus
`@randsum/ui/native/theme` with `lightTheme`, `darkTheme`,
`RollerThemeProvider` and `useRollerTheme`.

## Svelte

| Import               | What it is                                                     |
| -------------------- | -------------------------------------------------------------- |
| `@randsum/ui/svelte` | Types only: every tag's properties and events in Svelte markup |

## Server

| Import            | What it is                                                                  |
| ----------------- | --------------------------------------------------------------------------- |
| `@randsum/ui/ssr` | `renderToString(markup)`: HTML with each element's shadow root filled in    |

## State, data and logic

These render nothing.

| Import                     | Exports                                                        |
| -------------------------- | -------------------------------------------------------------- |
| `@randsum/ui/roller-state` | `RollerState`                                                  |
| `@randsum/ui/keys`         | `DEFAULT_KEYS`, `DICE_KEYS`, `CLEAR_KEY`, `CONSTANT_KEYS`, `modifierKeys`, `applyKey` |
| `@randsum/ui/presets`      | `modifierPresets`                                              |
| `@randsum/ui/check`        | `checkNotation`, `rollNotation`, `describe`                    |
