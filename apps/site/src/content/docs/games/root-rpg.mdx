The `@randsum/games/root-rpg` subpath provides mechanics for [Root RPG](https://magpiegames.com/pages/root-rpg), a tabletop roleplaying game set in the world of the Root board game. It uses a 2d6 + bonus system with success thresholds similar to Powered by the Apocalypse games.

roll({ bonus: 2 })   // Strong stat
roll({ bonus: 0 })   // No bonus
roll({ bonus: -1 })  // Penalty

// Advantage and disadvantage roll 3d6 and keep the best or worst two
roll({ bonus: 1, rollingWith: 'Advantage' })
roll({ bonus: 1, rollingWith: 'Disadvantage' })`} />

## API

### `roll(input: { bonus: number, rollingWith?: 'Advantage' | 'Disadvantage' })`

**Input:**

| Property | Type | Description |
|---|---|---|
| `bonus` | `number` | Stat modifier, an integer from -3 to +5 |
| `rollingWith` | `'Advantage' \| 'Disadvantage' \| undefined` | Roll 3d6, keep the 2 highest or lowest |

**Returns:** `GameRollResult` with:

| Property | Type | Description |
|---|---|---|
| `result` | `RootRpgRollResult` | `'strong_hit' \| 'weak_hit' \| 'miss'` |
| `total` | `number` | Sum of the kept dice + bonus |
| `rolls` | `RollRecord[]` | Raw dice data from the core roller |

## Outcomes

| Outcome | Total | Description |
|---|---|---|
| `strong_hit` | 10+ | Complete success: you achieve your goal |
| `weak_hit` | 7-9 | Partial success: you do it, but with a cost or complication |
| `miss` | 6- | Failure: things go badly |

## Error handling

Game `roll()` can throw two types of errors:

- **`ValidationError`** (from `@randsum/roller`): numeric input out of range, not an integer, or not finite (e.g., `bonus: 9` when the maximum is 5)
- **`SchemaError`** (from `@randsum/games/root-rpg`): game-specific issues like an invalid `rollingWith` value

<CodeExample code={`import { roll, SchemaError } from '@randsum/games/root-rpg'
import { ValidationError } from '@randsum/roller'

try {
  roll({ bonus: 9 })
} catch (error) {
  if (error instanceof ValidationError) {
    // Out-of-range bonus (must be -3 to 5)
    console.log(error.code)    // 'VALIDATION_ERROR'
  } else if (error instanceof SchemaError) {
    // e.g., invalid rollingWith enum value
    console.log(error.code)    // 'INVALID_INPUT_TYPE'
  }
}`} />
