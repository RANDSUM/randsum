A language model asked to roll dice makes the numbers up. RANDSUM gives agents
the real engine instead: the same `roll()` that powers the library, the Discord
bot and this site, with every step of the roll shown.

There are two ways in for Claude. In Claude Code, install the **plugin**: skills
for rolling, coding, odds and game specs, a `/roll` command, and the hosted
dice tools. In claude.ai, Claude Desktop or mobile, add the **connector** at
`https://api.randsum.dev/mcp`. The connector is an MCP server, so Cursor,
VS Code, ChatGPT and other MCP clients use that same URL. For agents without
MCP, the [RANDSUM API](/api/introduction/) gives the same rolls as plain JSON.

## Which one to use

| You use                                   | Install                                        | The agent gets                                                       |
| ----------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------- |
| Claude Code                               | [the plugin](/tools/claude-code-plugin/)       | the MCP tools, plus skills for notation, probability and game specs  |
| Claude (claude.ai, Desktop, mobile)       | [the connector](/tools/mcp/) at `https://api.randsum.dev/mcp` | `roll`, `validate` and `roll_game`        |
| Cursor, VS Code, ChatGPT, any MCP client  | the same URL, [set up per client](/tools/mcp/#any-other-mcp-client) | `roll`, `validate` and `roll_game` |
| Any agent with a fetch tool or a shell    | nothing: call [the HTTP API](/api/introduction/) | rolls, game results and random integers as JSON                    |
| An agent you are building                 | [`@randsum/roller`](/roller/getting-started/)  | the engine as a library, with no tool call in between                |

The plugin already connects the hosted server, so in Claude Code install the
plugin and skip the separate `claude mcp add`. To run the server yourself,
offline or without URL support, see the
[local server](/tools/mcp/#local-stdio-server).

## Docs agents can read

These pages are written for people and for agents alike:

- [`/llms.txt`](https://randsum.dev/llms.txt) is the short map of RANDSUM, its
  packages and its web surfaces, followed by every documentation page.
- [`/spec/llms-full.txt`](https://notation.randsum.dev/llms-full.txt) is the whole
  RANDSUM Dice Notation spec as one text file.
- Each documentation page has a button to copy it as Markdown or open it in a
  chat.
- [`https://api.randsum.dev/v1`](/api/introduction/) rolls dice, rolls for game
  systems and draws random integers over plain HTTP, for an agent with a fetch
  tool and nothing else.
