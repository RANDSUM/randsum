The **RANDSUM Discord Bot** is a Discord application for rolling dice in chat. It runs as a Cloudflare Worker that answers Discord's slash commands, and shows every step of each roll. Every command takes an optional `hidden:true`, which shows the result only to you. It has a command for every RANDSUM game except Salvage Union, which the official SURef bot handles.

## What a roll looks like

Each reply breaks the roll down step by step, coloured by outcome.

## Commands

### `/roll`

The core dice rolling command. Supports the full RANDSUM dice notation with detailed breakdowns showing individual die results, modifiers, and final totals.

<CodeExample lang="bash" code={`/roll notation:4d6L+2
/roll notation:2d20H
/roll notation:3d8+5`} />

### `/blades`

Roll Blades in the Dark action rolls. Takes the number of dice in your pool and returns the outcome (critical, success, partial, or failure), color-coded by outcome.

<CodeExample lang="bash" code={`/blades dice:3
/blades dice:2
/blades dice:0   # Zero dice: rolls 2d6 and keeps the lowest`} />

### `/fifth`

Roll D&D 5th Edition dice (1d20 + modifier). Supports advantage and disadvantage, and an optional `dc` to show success or failure. Natural 20s display in gold and natural 1s in crimson, so they stand out at a glance.

<CodeExample lang="bash" code={`/fifth modifier:5
/fifth modifier:3 rolling_with:Advantage
/fifth modifier:4 dc:15
/fifth rolling_with:Disadvantage
/fifth   # Straight 1d20`} />

### `/dh`

Roll Daggerheart's Hope and Fear dice. Supports modifiers, advantage and disadvantage, amplifying either die, and an optional `difficulty` that resolves the roll into success or failure.

<CodeExample lang="bash" code={`/dh modifier:5 rolling_with:Advantage
/dh modifier:3 rolling_with:Disadvantage
/dh amplify_hope:true amplify_fear:false
/dh modifier:2 difficulty:14`} />

### `/fate`

Roll Fate Core: four Fate dice (`4dF`) plus a skill rating, read off the Fate ladder from Terrible to Legendary. Add an opposition to resolve the shifts into a Fate outcome.

<CodeExample lang="bash" code={`/fate skill:3
/fate skill:2 opposition:3
/fate   # Mediocre (+0) skill`} />

### `/root`

Roll Root RPG moves. Rolls 2d6 plus an optional modifier and returns the outcome (Strong Hit, Weak Hit, or Miss). Name the `stat` the move uses, and roll with advantage or disadvantage to roll 3d6 and keep the best or worst two.

<CodeExample lang="bash" code={`/root modifier:2 stat:Might
/root modifier:-1 rolling_with:Disadvantage
/root   # No modifier`} />

### `/salvageunion`

Salvage Union rolls have moved. This command points you to [SURef](https://salvageunion.io/discord), the official bot from salvageunion.io, which rolls every Salvage Union table and looks up any chassis, system, module, or piece of equipment. It replaces the old `/su` command, which no longer exists.

<CodeExample lang="bash" code={`/salvageunion`} />

### `/pbta`

Roll Powered by the Apocalypse moves (2d6 + stat). Supports forward and ongoing bonuses, and advantage and disadvantage.

<CodeExample lang="bash" code={`/pbta stat:2
/pbta stat:1 forward:1
/pbta stat:3 rolling_with:Advantage
/pbta stat:0 ongoing:1`} />

### `/notation`

Display a reference guide for RANDSUM dice notation. Shows all available modifiers, syntax, and examples.

<CodeExample lang="bash" code={`/notation`} />

### `/help`

Lists all available RANDSUM slash commands with descriptions.

## Game Support

Six games have their own slash command, each resolving the roll by that game's rules:

  <Card href="/games/blades/" eyebrow="/blades" title="Blades in the Dark" accent="var(--game-blades)">

  </Card>
  <Card href="/games/pbta/" eyebrow="/pbta" title="Powered by the Apocalypse" accent="var(--game-pbta)">

Salvage Union is served by the [SURef bot](https://salvageunion.io/discord) instead; `/salvageunion` points there. The `@randsum/games/salvageunion` package is still published and usable in your own code.

## Features

- **Detailed breakdowns**: individual die results, modifiers and step-by-step calculations
- **Full notation support**: every RANDSUM dice notation feature (drop, reroll, explode and the rest)
- **Game-specific commands**: a dedicated command for each supported game
- **Color-coded results**: results are visually distinct by outcome
- **Private rolls**: `hidden:true` on any command shows the result only to you
- **Reroll button**: roll the same thing again from the reply

## Self-Hosted Setup

If you prefer to run the bot yourself:

<CodeExample lang="bash" code={`# From the monorepo root
cd apps/discord-bot

# Install dependencies
bun install

# Set up environment variables
cp .env.example .env

# Register the slash commands with Discord
bun run deploy-commands

# Run the Worker locally (wrangler dev)
bun run dev`} />

For detailed setup instructions, see the [Discord Bot source on GitHub](https://github.com/RANDSUM/randsum/tree/main/apps/discord-bot).
