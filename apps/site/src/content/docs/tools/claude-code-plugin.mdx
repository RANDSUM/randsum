RANDSUM provides a **Claude Code plugin** with four skills that give AI agents specialized knowledge for tabletop RPG dice mechanics, and a `/roll` command for rolling your own dice. It is one of the ways to [give an AI agent RANDSUM](/tools/agents/). In claude.ai, Claude Desktop or mobile, add its MCP server as a [Claude connector](/tools/mcp/#hosted-server-no-install) instead, at `https://api.randsum.dev/mcp`.

## What is a Claude Code skill?

A skill is a markdown document that gives Claude specialized knowledge. When Claude loads a RANDSUM skill, it learns domain-specific concepts — dice notation syntax, probability math, or the `.randsum.json` spec format — and can apply them to your questions without you needing to explain the domain.

Skills activate automatically based on context. Ask naturally:

```
Roll 4d6 drop lowest for my strength score
What are the odds of rolling 15+ on 3d6?
Create a .randsum.json spec for Ironsworn
```

Or invoke explicitly with `/randsum:dice-rolling`, `/randsum:randsum-library`, `/randsum:dice-probability`, or `/randsum:game-spec-creator` (plugin skills are namespaced by the plugin name).

## Roll your own dice: `/roll`

The plugin adds a `/roll` command that rolls on your machine with the RANDSUM engine, with no model turn and no tokens:

```
/roll 4d6L
/roll 1d20 + 5, 2d6
```

The result prints at once and stays on the status line, and Claude is told the number as your roll, so it reacts to it instead of rolling for you. That suits a game where Claude is the GM and you want to throw your own dice. `/roll` with no notation rolls a d20.

`/roll` is a Claude Code mod (a hooks module), an early-access feature of recent Claude Code builds. On a build without it, the command is simply absent and the rest of the plugin works as before. It is not available in claude.ai or Claude Desktop chat; there, ask Claude to roll and the connector does it.

## Setup

All skill files live in the [`plugins/randsum/skills/`](https://github.com/RANDSUM/randsum/tree/main/plugins/randsum/skills) directory.

<Tabs>
<TabItem label="Claude Code">

Add the RANDSUM marketplace and install the plugin from inside Claude Code:

<CodeExample lang="bash" code={`/plugin marketplace add RANDSUM/randsum
/plugin install randsum@randsum`} />

On Claude Code 2.1.275 or later, one command does both: `/plugin install randsum --marketplace RANDSUM/randsum`.

The plugin also connects the hosted [`@randsum/mcp`](/tools/mcp/) server at `https://api.randsum.dev/mcp`, so the skills can roll with the real engine instead of simulating, with nothing to install. You do not need a separate `claude mcp add`.

**Staying current.** The plugin tracks the marketplace's commits rather than a version number. Run `/plugin marketplace update randsum` to pick up changes, or turn on **Enable auto-update** for the `randsum` marketplace under **Marketplaces** in `/plugin`.

**For a whole team.** Run these once in your project's shell and commit the `.claude/settings.json` they write. Everyone who trusts the folder is then offered the marketplace and the plugin:

<CodeExample lang="bash" code={`claude plugin marketplace add RANDSUM/randsum --scope project
claude plugin install randsum@randsum --scope project`} />

## Skill details

### Dice Rolling

The core skill for an agent rolling dice in conversation. It turns a natural-language request into a call to the RANDSUM MCP tools (`roll`, `roll_game`, `validate`) or the [HTTP API](/api/introduction/), and reports the result for seven supported game systems: D&D 5e, Blades in the Dark, Daggerheart, Fate Core, PbtA, Root RPG, and Salvage Union.

**What the agent learns:**
- Never to invent a roll, and which tool to reach for first (MCP, then the HTTP API, then a local RNG)
- How common phrasings map to calls ("roll stats" is `4d6Lx6`, "Blades with 3 dice" is `roll_game` with `rating: 3`)
- RANDSUM notation (`4d6L`, `2d20H+5`, `3d6!`, `d%`, `4dF`, etc.) and each game's inputs and outcomes
- How to report dice, total and meaning in one compact block

**Files:**
- [`plugins/randsum/skills/dice-rolling/SKILL.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/dice-rolling/SKILL.md) — main skill definition
- [`plugins/randsum/skills/dice-rolling/references/NOTATION.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/dice-rolling/references/NOTATION.md) — full notation reference
- [`plugins/randsum/skills/dice-rolling/references/GAME_SYSTEMS.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/dice-rolling/references/GAME_SYSTEMS.md) — game system mechanics

### RANDSUM Library

For an agent writing code. Teaches which package fits (`@randsum/roller`, a `@randsum/games` subpath, or the REST API from another language) and how to use it well.

**What the agent learns:**
- `roll()` arguments and the result shape (`total`, `values`, per-group `rolls` with `initialRolls`)
- Validating user-typed notation with `validateNotation` and `suggestNotationFix`, and catching `RandsumError`
- Each game's typed `roll()` input and result union
- Seeded rolls for tests, narrow subpath imports for small bundles, and when to use the REST API

**Files:**
- [`plugins/randsum/skills/randsum-library/SKILL.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/randsum-library/SKILL.md) — main skill definition
- [`plugins/randsum/skills/randsum-library/references/GAMES.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/randsum-library/references/GAMES.md) — every game's API

### Dice Probability

Teaches an agent to analyze probability distributions for dice rolls. Handles exact enumeration for small outcome spaces and Monte Carlo simulation for complex rolls.

**What the agent learns:**
- Expected values, variance, and standard deviation for any notation
- Probability of hitting specific thresholds (e.g., "odds of 15+ on 3d6")
- Comparative analysis ("advantage vs. flat +2 bonus")
- Game-system outcome probabilities (e.g., "chance of critical success in Blades")

**Files:**
- [`plugins/randsum/skills/dice-probability/SKILL.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/dice-probability/SKILL.md) — main skill definition
- [`plugins/randsum/skills/dice-probability/references/PROBABILITY_TABLES.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/dice-probability/references/PROBABILITY_TABLES.md) — precomputed reference tables

### Game Spec Creator

Teaches an agent the `.randsum.json` spec format — a declarative JSON Schema for describing tabletop RPG dice mechanics. Specs define a four-stage pipeline (Dice → Modify → Resolve → Outcome) and generate typed TypeScript `roll()` functions via codegen.

**What the agent learns:**
- The full `.randsum.json` schema (pools, modifiers, conditions, outcome tables)
- How to translate natural-language game rules into declarative specs
- Reference resolution (`$ref` for reusable components)
- Validation rules and common patterns across game systems

**Files:**
- [`plugins/randsum/skills/game-spec-creator/SKILL.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/game-spec-creator/SKILL.md) — main skill definition
- [`plugins/randsum/skills/game-spec-creator/references/SPEC_EXAMPLES.md`](https://github.com/RANDSUM/randsum/blob/main/plugins/randsum/skills/game-spec-creator/references/SPEC_EXAMPLES.md) — example specs for existing game systems

## Programmatic usage

If you're building a custom agent, you can also use `@randsum/roller` directly:

<CodeExample lang="bash" code={`bun add @randsum/roller`} />

<CodeExample code={`import { roll } from '@randsum/roller'

const result = roll('4d6L')
console.log(result.total)  // Sum after dropping lowest
console.log(result.rolls)  // Individual die results`} />

See the [Roller documentation](/roller/introduction/) for the full API.
